# Beginner Level Questions

## 1. What is JDBC?

JDBC (Java Database Connectivity) is an API that allows Java applications to communicate with relational databases.

---

## 2. What is the full form of JDBC?

Java Database Connectivity.

---

## 3. Why is JDBC used?

JDBC is used to connect Java applications with databases and perform database operations such as:

- Create
- Read
- Update
- Delete

---

## 4. What is a JDBC Driver?

A JDBC Driver is a software component that enables communication between a Java application and a database.

---

## 5. Name the databases used in this project.

- MySQL
- Oracle

---

## 6. Which package contains JDBC classes?

```java
java.sql
```

---

## 7. What are the main JDBC interfaces?

- Driver
- Connection
- Statement
- PreparedStatement
- CallableStatement
- ResultSet

---

## 8. What is Connection?

Connection represents the connection between a Java application and a database.

---

## 9. What is Statement?

Statement is used to execute SQL queries.

---

## 10. What is PreparedStatement?

PreparedStatement is a precompiled SQL statement used to execute parameterized queries efficiently and securely.

---

# Intermediate Level Questions

## 11. What are the steps to connect Java with a database?

1. Import JDBC package.
2. Load the JDBC Driver.
3. Establish the database connection.
4. Create Statement or PreparedStatement.
5. Execute SQL query.
6. Process the result.
7. Close all resources.

---

## 12. Why is PreparedStatement preferred over Statement?

PreparedStatement:

- Improves performance.
- Prevents SQL Injection.
- Supports parameterized queries.
- Is easier to maintain.

---

## 13. What is ResultSet?

ResultSet stores the data returned by a SELECT query.

---

## 14. What is SQLException?

SQLException occurs when an error happens while interacting with the database.

---

## 15. Why should database resources be closed?

Closing resources:

- Prevents memory leaks.
- Improves application performance.
- Releases database connections.
- Maintains application stability.
