# MySQL Database

This folder contains all SQL scripts required to set up the **MySQL** database for the **JDBCAPP - Database Application** project.

The SQL files in this folder are executed in sequence to prepare the database before running the Java application.

---

# Purpose

The purpose of this folder is to provide all MySQL-related database scripts in one place so that beginners can easily set up the project without writing SQL manually.

---

# Files in this Folder

| File Name | Description |
|-----------|-------------|
| `create_database.sql` | Creates the project database. |
| `create_table.sql` | Creates the required tables. |
| `sample_data.sql` | Inserts sample records into the database. |

---

# Execution Order

Execute the SQL files in the following order:

1. `create_database.sql`
2. `create_table.sql`
3. `sample_data.sql`

Executing the files in this order ensures that the database is created before tables are added, and tables exist before sample data is inserted.

---

# Database Used

# Learning Outcome

After completing the SQL scripts in this folder, you will be able to:

- Create a MySQL database.
- Create the required project tables.
- Insert sample records.
- Prepare the database for the JDBC application.
