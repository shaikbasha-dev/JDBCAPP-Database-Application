# Oracle Database

This folder contains all SQL scripts required to set up the **Oracle** database for the **JDBCAPP - Database Application** project.

The SQL files in this folder are executed in sequence to prepare the Oracle database before running the Java application.

---

# Purpose

The purpose of this folder is to provide all Oracle-related database scripts in one place so that beginners can easily set up the project without writing SQL manually.

---

# Files in this Folder

| File Name | Description |
|-----------|-------------|
| `create_database.sql` | Creates the required database user/schema for the project. |
| `create_table.sql` | Creates the required tables. |
| `sample_data.sql` | Inserts sample records into the database. |

---

# Execution Order

Execute the SQL files in the following order:

1. `create_database.sql`
2. `create_table.sql`
3. `sample_data.sql`

Executing the files in this order ensures that the database environment is prepared before tables are created and sample data is inserted.

# Learning Outcome

After completing the SQL scripts in this folder, you will be able to:

- Prepare the Oracle database environment.
- Create the required project tables.
- Insert sample records.
- Prepare the database for the JDBC application.
