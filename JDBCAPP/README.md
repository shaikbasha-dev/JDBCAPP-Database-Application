# JDBCAPP

Welcome to the **JDBCAPP** project.

This folder contains the complete Java source code for the **JDBCAPP - Database Application** project.

The project is developed using Java and JDBC to demonstrate database connectivity with MySQL and Oracle through a menu-driven application.

All Java packages, classes, SQL operations, and project resources required for the application are organized inside this folder.

The source code is implemented step by step to make learning simple, practical, and beginner-friendly.
