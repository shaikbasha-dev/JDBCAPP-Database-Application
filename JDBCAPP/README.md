# JDBCAPP

Welcome to the **JDBCAPP - Database Application** project.

This folder contains the complete Eclipse Java project for the JDBCAPP application.

The project is developed using Java and JDBC to demonstrate database connectivity with MySQL and Oracle through a menu-driven console application.

---

# Purpose

The purpose of this folder is to organize all Java source code, project configuration, and required libraries in a single location.

This project is designed to help beginners understand how Java applications communicate with relational databases using JDBC.

# Package Description

## com.jdbcapp.main

Contains the main class that starts the application and displays the database selection menu.

---

## com.jdbcapp.mysql

Contains all MySQL database operations.

---

## com.jdbcapp.oracle

Contains all Oracle database operations.

---

## com.jdbcapp.util

Contains reusable utility classes used throughout the project.

# Learning Outcome

After completing this project, you will be able to:

- Create a Java JDBC project.
- Connect Java with MySQL.
- Connect Java with Oracle.
- Develop a menu-driven application.
- Perform CRUD operations.
- Understand the structure of a JDBC project.
