# Project Setup

After understanding the project architecture, the next step is to create the Java project that will be used to develop the JDBC application.

This section explains how to prepare the development environment before writing any JDBC code.

---

# Project Name

The Java project used in this repository is named:

```text
JDBCAPP
```

---

# Steps to Create the Java Project

### Step 1

Open **Eclipse IDE**.

---

### Step 2

Click

```text
File
    ↓
New
    ↓
Java Project
```

---

### Step 3

Enter the project name.

```text
JDBCAPP
```

---

### Step 4

Click **Finish**.

---

# Project Structure

After creating the project, Eclipse automatically creates the following structure.

```text
JDBCAPP
│
├── src
├── JRE System Library
└── README.md
```

---

# Purpose of Each Component

## src

The **src** folder contains all Java source files.

Every Java package and Java class will be created inside this folder.

---

## JRE System Library

This library contains all the predefined Java classes required to develop Java applications.

Examples:

- String
- Scanner
- System
- Connection
- DriverManager

---

# Why Create a Java Project?

Creating a Java project helps to:

- Organize source code.
- Manage Java packages.
- Compile programs.
- Execute applications.
- Maintain project structure.

---

# What Will Be Created Next?

After creating the Java project, we will create the following packages.

```text
com.jdbcapp.main

com.jdbcapp.mysql

com.jdbcapp.oracle

com.jdbcapp.util
```

Each package has a specific responsibility within the project.
