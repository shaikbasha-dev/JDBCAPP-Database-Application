# About the Repository

**JDBCAPP - Database Application** is a structured learning repository created to demonstrate how a Java application connects to different Database Management Systems (DBMS) using JDBC.

The project follows a simple and practical approach where the user first selects a database, establishes a connection, and then performs database operations through a menu-driven application.

The repository is written in a beginner-friendly manner with detailed explanations, complete source code, and practical implementation to help learners understand JDBC from the basics.

---
