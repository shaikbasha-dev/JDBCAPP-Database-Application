# Project Introduction

Welcome to the **JDBCAPP - Database Application** project.

This project is designed to help beginners understand how Java applications communicate with different databases using JDBC (Java Database Connectivity).

Unlike traditional JDBC projects that work with only one database, this application allows the user to select a database before performing any database operations.

The project follows a simple menu-driven approach, making it easy to understand and implement.

---

# What You Will Learn

After completing this project, you will be able to understand:

- What is JDBC?
- Why JDBC is required?
- How Java communicates with a database.
- How to connect Java with MySQL.
- How to connect Java with Oracle.
- How to build a menu-driven JDBC application.
- How CRUD operations work using JDBC.
- How to organize a JDBC project properly.

---

# Project Objective

The objective of this project is to build a database-independent JDBC application where the user can:

- Select a database.
- Establish a database connection.
- Perform database operations.
- Exit the application safely.

---
