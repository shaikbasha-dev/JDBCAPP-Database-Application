# Software Requirements

Before developing the **JDBCAPP - Database Application**, it is important to install and configure the required software. Each software plays a specific role in the project development process.

This section explains all the software required to successfully create, execute, and test the JDBC application.

---

# Required Software

The following software is required:

- Java Development Kit (JDK)
- Eclipse IDE
- MySQL Database
- Oracle Database
- MySQL Connector/J
- Oracle JDBC Driver

---

# 1. Java Development Kit (JDK)

The Java Development Kit (JDK) provides the tools required to develop, compile, and execute Java programs.

### Purpose

- Write Java programs
- Compile Java source code
- Execute Java applications

---

# 2. Eclipse IDE

Eclipse is an Integrated Development Environment (IDE) used for developing Java applications.

### Purpose

- Create Java Projects
- Write Java Programs
- Debug Applications
- Execute Programs

---

# 3. MySQL Database

MySQL is an open-source Relational Database Management System (RDBMS).

### Purpose

- Store Application Data
- Execute SQL Queries
- Perform CRUD Operations

---

# 4. Oracle Database

Oracle Database is an enterprise-level Relational Database Management System.

### Purpose

- Store Business Data
- Execute SQL Statements
- Perform Database Operations

---

# 5. MySQL Connector/J

MySQL Connector/J is the official JDBC driver provided by MySQL.

### Purpose

- Connect Java Applications to MySQL Database

---

# 6. Oracle JDBC Driver

Oracle JDBC Driver enables Java applications to communicate with Oracle Database.

### Purpose

- Connect Java Applications to Oracle Database

---

# System Requirements

| Component | Requirement |
|-----------|-------------|
| Operating System | Windows 10 or Later |
| JDK | Java 8 or Above |
| IDE | Eclipse IDE |
| Databases | MySQL & Oracle |
| RAM | Minimum 4 GB |
| Disk Space | Minimum 2 GB Free Space |

---

# Software Installation Order

Install the software in the following order:

1. Java Development Kit (JDK)
2. Eclipse IDE
3. MySQL Database
4. Oracle Database
5. MySQL Connector/J
6. Oracle JDBC Driver
